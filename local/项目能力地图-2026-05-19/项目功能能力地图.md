# 项目功能能力地图：dify-all-in-one

## A. 项目定位

`dify-all-in-one` 是面向 Hugging Face Docker Space 的 Dify 单容器 Demo 工程，用于企业内训、课程演示、PoC 和快速功能验证；它不是生产部署方案。依据：`README.md:12-16`、`docs/project-overview.md:1-19`。

- 已看到的能力：entrypoint 负责初始化和迁移，Supervisor 负责长期多进程，wrapper 和 wait-for-core 负责环境注入和依赖等待。

- 主要缺口：migration 顺序和 Supervisor program 状态还缺少容器内实测。

### 数据持久化与配置管理

- 已看到的能力：runtime defaults、generated env、bucket-lite、PostgreSQL fallback、dump backup、非敏感配置摘要都已有代码证据。
- 主要证据：`docker/dify.env.runtime:18-32`、`docker/entrypoint.sh:171-261`、`docker/postgres-backup-loop:30-100`、`docker/ops_service.py:481-493`、`git log: 400933d, 91bb56f, 7f7f5d8, 50ab7ff`。
