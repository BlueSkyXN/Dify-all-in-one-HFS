# Function Spec Card: FP-005

## Identity

- **ID:** FP-005
- **Name:** bucket-lite `/data` -> `/persist` 映射
- **Capability domain:** CAP-002 启动初始化与持久化编排
- **Status tags:** specified;implemented
- **Maturity:** M4

## Behavior

- **User / actor:** 容器 entrypoint
- **Trigger:** 容器启动时执行 `prepare_dirs`
- **Preconditions:** `docker/dify.env.runtime` 已可读取；`/persist` 可能存在也可能不存在
- **Inputs:** `PERSIST_MODE`、`PERSIST_ROOT`、`RUNTIME_ROOT`、`REDIS_PERSISTENCE`、`PLUGIN_CWD_PERSISTENCE`
- **Processing logic:**
  1. 读取 `PERSIST_MODE`，若为 `auto` 则检查 `/persist` 是否为挂载点且可写。
  2. 若进入 bucket-lite，创建核心 state 目录与 scratch 目录。
  3. 用 symlink 把 `/data/postgres`、`/data/config`、`/data/dify/storage`、plugin 目录映射到目标路径。
  4. 对 Redis 与 plugin cwd 根据开关决定放入 `/persist` 还是 `${RUNTIME_ROOT}`。
  5. 写入 `persist-active` 标记，并继续后续 bootstrap。
- **Outputs:** 统一的 `/data/...` 运行时视图；bucket-lite 激活标记；目录和 symlink 准备完成
- **State transitions:** `PERSIST_MODE=auto` -> `bucket` or `legacy`
- **Side effects:** 创建目录、复制目录初始内容、替换为 symlink

## Exceptions and edge cases

| Case | Trigger | Expected handling | Evidence |
|---|---|---|---|
| `/persist` 不可写 | `PERSIST_MODE=bucket` 且挂载不可写 | 直接退出 | `docker/entrypoint.sh:122-129` |
| 源目录和目标目录都已有内容 | 迁移已存在 state | 保留 target 并打印说明 | `docker/entrypoint.sh:160-164` |
| `/data` 对 UID 1000 不可写 | volume 权限错误 | 直接退出 | `docker/entrypoint.sh:251-255` |

## Non-functional requirements

- **Permissions:** 必须兼容 rootless UID `1000`
- **Logging / audit:** 通过 `log()` 打印持久化模式与错误上下文
- **Performance:** 主要是启动阶段目录准备，无持续热路径
- **Concurrency / idempotency:** 多次启动应能重用已有目标目录，不应重复破坏已存在 target
