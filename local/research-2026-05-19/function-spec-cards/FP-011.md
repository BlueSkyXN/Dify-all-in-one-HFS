# Function Spec Card: FP-011

## Identity

- **ID:** FP-011
- **Name:** 单端口 Nginx 路由合同
- **Capability domain:** CAP-003 进程编排与单端口请求路由
- **Status tags:** specified;implemented
- **Maturity:** M4

## Behavior

- **User / actor:** 浏览器、API client、Hugging Face iframe
- **Trigger:** 外部请求命中 `7860`
- **Preconditions:** Nginx 已启动；对应 upstream 进程存在
- **Inputs:** URL path、HTTP headers、WebSocket upgrade headers
- **Processing logic:**
  1. 对 `/nginx-health` 直接本地返回 `ok`。
  2. 对 `/healthz`、`/_ops/*`、`/_admin/*` 代理到本地 operator 服务。
  3. 对 `/console/api`、`/api`、`/v1`、`/files`、`/mcp`、`/triggers` 代理到 Dify API。
  4. 对 `/socket.io/` 保留 upgrade headers。
  5. 对 `/e/` 代理到 plugin-daemon 并注入 `Dify-Hook-Url`。
  6. 其他路径落到 Dify Web。
- **Outputs:** 单一公网端口上的多路径应用合同
- **State transitions:** 无显式状态机
- **Side effects:** 记录 JSON access log 到 stdout

## Exceptions and edge cases

| Case | Trigger | Expected handling | Evidence |
|---|---|---|---|
| `/_ops` 或 `/_admin` 缺末尾斜杠 | request path 是裸前缀 | 308 redirect 到带 `/` 的路径 | `docker/nginx.conf:72-84` |
| HF iframe 被上游 `X-Frame-Options` 阻断 | Dify Web 默认 deny | 隐藏上游 header 并补 `frame-ancestors` CSP | `docker/nginx.conf:55-61` |
| WebSocket route 丢 header | `socket.io` 或 terminal 连接 | 显式设置 `Upgrade` / `Connection` | `docker/nginx.conf:99-106`, `docker/nginx.conf:138-143` |

## Non-functional requirements

- **Permissions:** 无额外权限要求
- **Logging / audit:** JSON access log 包含 `request_id`、`uri`、`status`、`upstream_*`
- **Performance:** 路由是静态配置，非模板渲染
- **Concurrency / idempotency:** 多请求并发依赖 Nginx worker 和 upstream 服务
