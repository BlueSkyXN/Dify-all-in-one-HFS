# Function Spec Card: FP-016

## Identity

- **ID:** FP-016
- **Name:** `/_ops/health` 与 `/healthz` 健康聚合
- **Capability domain:** CAP-005 只读运维诊断
- **Status tags:** specified;implemented
- **Maturity:** M4

## Behavior

- **User / actor:** operator、smoke script、外部监控
- **Trigger:** 请求 `/healthz` 或 `/_ops/health`
- **Preconditions:** `ops-service` 已启动；默认 probe 或额外 probe 已配置
- **Inputs:** `OPS_DEFAULT_CHECKS_ENABLED`、`OPS_EXTRA_HTTP_CHECKS_JSON`、`OPS_EXTRA_TCP_CHECKS_JSON`、`OPS_EXTRA_COMMAND_CHECKS_JSON`
- **Processing logic:**
  1. 构造默认 probe 集合：PostgreSQL、Redis、Plugin Daemon TCP、Sandbox TCP、Dify API/Web/Nginx/setup/init HTTP。
  2. 追加额外 HTTP/TCP/command probes。
  3. 并发执行 probe，收集 `ok`、status、duration、sample/error。
  4. `/healthz` 返回 public 版结果；`/_ops/health` 再附带 supervisor 和 version 信息。
- **Outputs:** 聚合后的健康 JSON；失败时 `/healthz` 返回 503
- **State transitions:** 无显式状态机
- **Side effects:** 只读执行本地命令和 HTTP/TCP 连接

## Exceptions and edge cases

| Case | Trigger | Expected handling | Evidence |
|---|---|---|---|
| 关闭默认 probes 且没有额外 probes | `OPS_DEFAULT_CHECKS_ENABLED=false` 且 extra 为空 | 返回不健康并提示 `no checks configured` | `docker/ops_service.py:454-460` |
| command probe 超时 | 外部命令迟迟不返回 | 返回 timeout，而不是 hang 死整个请求 | `docker/ops_service.py:217-249` |
| HTTP probe 期望状态非 200 | 配置了 `expected_status` | 仅在目标状态命中时 `ok=true` | `docker/ops_service.py:258-286`, `docker/ops_service.py:321-335` |

## Non-functional requirements

- **Permissions:** 只能执行部署时配置好的只读命令
- **Logging / audit:** 本体走 stdout/stderr，不写业务数据
- **Performance:** 并发执行 probes，受 `MAX_CHECKS=32` 限制
- **Concurrency / idempotency:** 每次请求都重新采样，不缓存状态
