# Function Spec Card: FP-021

## Identity

- **ID:** FP-021
- **Name:** admin 白名单动作与审计日志
- **Capability domain:** CAP-006 受控管理与文件边界
- **Status tags:** specified;implemented
- **Maturity:** M4

## Behavior

- **User / actor:** 持有 `ADMIN_TOKEN` 的 operator
- **Trigger:** 调用 `/_admin/api/actions/*`
- **Preconditions:** `ADMIN_ENABLED=true` 且 `ADMIN_TOKEN` 非空；请求已通过 auth；写请求带 `X-Admin-CSRF`
- **Inputs:** `service`、`confirm=true`、HTTP method
- **Processing logic:**
  1. 读取 action catalog，只允许 `restart-service`、`reload-nginx`、`run-health-checks`。
  2. 对 `restart-service` 校验 service 是否在白名单中。
  3. 对 `reload-nginx` 先执行 `nginx -t`，通过后再 reload。
  4. 对 `run-health-checks` 调用 `dify-demo-healthcheck`。
  5. 所有动作生成 `action_id` 并写入 `ADMIN_AUDIT_LOG`。
- **Outputs:** JSON action result，包含 `ok`、`action_id`、底层命令结果
- **State transitions:** 无业务状态机；只影响运行中的进程状态
- **Side effects:** 重启 supervisor program、reload Nginx、写 audit JSONL

## Exceptions and edge cases

| Case | Trigger | Expected handling | Evidence |
|---|---|---|---|
| service 不在重启白名单 | 请求任意 service 名称 | 返回 400 和 allowed_services | `docker/admin_service.py:306-315` |
| 缺少 `confirm=true` | POST action body 不完整 | 返回 400 | `docker/admin_service.py:310-321`, `docker/admin_service.py:341-347` |
| `ADMIN_ENABLED=true` 但 token 为空 | admin 被误开启 | 返回 503，不提供可用管理面 | `docker/admin_service.py:954-960` |

## Non-functional requirements

- **Permissions:** 不能接收任意 shell command；只能执行白名单命令
- **Logging / audit:** 每次动作写 `ADMIN_AUDIT_LOG`，不记录 token 或文件内容
- **Performance:** 动作是低频 operator 触发，不追求高吞吐
- **Concurrency / idempotency:** `reload-nginx` 先 `nginx -t`；重启动作依赖 supervisor 语义，不承诺幂等外部效果
